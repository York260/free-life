# Free Life

Android 提醒 App:說一句話或打一行字就能建立提醒,到時間用「鬧鐘等級」響鈴(靜音、勿擾模式下也會響)。

## 第一版(v0.1)功能

- 打字建立提醒;手機鍵盤上的麥克風可以直接語音輸入。
- 自動分成兩種,每一筆都有開始時間:
  - **排程**:有開始和結束時間(例如「明天下午3點到4點看牙醫」「14:00-15:30 開會」「明天早上9點開會2小時」),開始時響鬧鐘。
  - **小任務**:只有開始時間(例如「買牛奶」會問什麼時候開始,可選「現在」;「10分鐘後倒垃圾」開始時響鈴)。沒有指定時間的,開始時間就是記下它的時刻,不響鈴。
- 缺資訊會追問:只說「3點」會問上午或下午;只說日期會問幾點開始;有開始時間卻沒結束時間會問到幾點結束(可選「沒有結束時間」變成小任務);沒有任何時間會問什麼時候開始;看診、開會、餐督這類事會問地點(可略過)。
- 鬧鐘響起時可以「完成」、「延後 10 分鐘」、「延後 1 小時」。
- 使用手機系統的鬧鐘排程,省電模式下也準時;手機重開機後會自動重新排程。
- 資料只存在手機裡。只有在你自己填入 Claude API 金鑰並按下「確認行程」時,才會把今明兩天的行程標題送到 Anthropic 產生建議。

可以輸入的例子:

```
明天下午3點看牙醫
後天早上8點半開會 @三樓會議室
明天 14:00-15:30 訓練
下午3點到下午5點 勤務
下週三 15:30 勤務餐督
10月15日晚上七點聚餐
10分鐘後倒垃圾
買牛奶
```

## 安裝到手機

1. 把這個 repo 的程式推到 `main`,GitHub Actions 會自動編譯(約 3 到 5 分鐘),看 **Actions** 頁籤的 *Build APK* 是否打勾。
2. 用手機打開這個 repo 的 **Releases**,進入 `最新版`,下載 `FreeLife.apk`(私人 repo 需要先登入 GitHub)。
3. 點開 APK 安裝,第一次會要求允許「安裝未知來源應用程式」。
4. 新版直接重新下載安裝即可覆蓋,提醒資料會保留(APK 使用固定簽章)。

## 第一次使用要做的設定

1. 允許**通知**(Android 13 以上),否則鬧鐘不會響。
2. Android 14 以上要允許**全螢幕通知**,鎖屏時才會跳出鬧鐘畫面。
3. 按畫面最下方的「測試鬧鐘(10 秒後響)」,鎖屏、靜音、開勿擾各測一次。
4. 部分品牌(小米、OPPO、vivo、三星)要把 Free Life 的電池設定改成「不限制」,並允許自動啟動,避免被系統省電機制擋掉。

## 每日確認(v0.2)

- 每天早上(預設 07:30,可在「設定」修改)跳出「確認今天的行程」通知,點開就是每日確認畫面。
- 畫面列出今天剩下的與明天的排程,按「確認行程,給我三點建議」後給三點建議,例如:
  - 明天有看診,今天要不要先打電話確認預約與時間?
  - 明天最早 8:00 就有事,要不要設起床鬧鐘?
  - 中午有會議,要不要提早買午餐?
- 部分建議可以一鍵「加入提醒」。建議只在畫面裡看,不會另外發通知打擾你。
- 預設使用內建規則,不需要網路。在「設定」填入 Claude API 金鑰(選填)後,改由 Claude 產生建議;AI 失敗時會自動退回內建建議。
- Claude API 與 Claude Pro 訂閱是分開計費,需要自己到 Console 儲值取得金鑰。

## 編輯與衝突提示(v0.3)

- 點清單裡的任何一項可以編輯:標題、地點、開始時間、結束時間(有結束時間就是排程)、是否在開始時響鈴。
- 新增或修改時,如果和別的排程時間重疊,會在畫面上提示「與「開會」(時段)時間重疊」,點該項目就能改時間。
- 提醒響起時,如果你正在開會(別的排程正在進行),不會直接大響,而是只震動一下並在畫面上方顯示橫幅,可以選:
  - **會後再提醒**:延後到那場排程結束後。
  - **照常響**:馬上正常響鈴。
  - **關閉**:這則提醒不用了。
  3 分鐘沒處理就自動改成正常響鈴,不會漏掉。可以在「設定」關閉這個行為。長度超過 8 小時的排程(例如出差)不算開會。
- 每日確認會把重疊的行程列為建議。
- 手機的勿擾如果是「完全靜音」,鬧鐘也會被系統擋掉,主畫面會出現紅色提示卡。
- 限制:Android 只允許 App 在執行中接收「勿擾開關變化」,所以目前不是在你一開勿擾時就通知,而是在提醒響起或新增行程時判斷衝突。

## 重複與提前提醒(v0.4)

- 可以直接說:「每週三下午3點勤務餐督」「平日早上8點打卡」「每天晚上8點吃藥」「每月15號繳費」。也可以在編輯視窗選重複。
- 重複的項目永遠停在「下一次」的時間。響起時,這一次會變成一筆單次提醒,可以完成或延後;系列則自動排到下一次。
- 重複項目的勾選代表「略過這次」,不會結束整個系列;要停掉整個系列請刪除,或在編輯視窗把重複改成「不重複」。
- 提前提醒:「下午3點開會 提前30分鐘」或「下午3點開會 30分鐘前提醒我」,會在開始前先響。編輯視窗也可以選。
- 開會前主動警告:排程開始前 10 分鐘,如果那段時間內有別的提醒會響,會先通知你「期間有哪些提醒會被靜音」,點開就能改時間或關閉。沒有衝突就不會通知。
- 手機重開機後,重複提醒錯過的次數會直接略過,排到下一次。

## AI 助理(v0.5)

主畫面按「🎤 助理」進入對話。個性預設像鋼鐵人的賈維斯:沉穩有禮、效率第一、帶一點乾冷幽默,稱呼你「長官」。助理的名字、對你的稱呼、語氣都可以在「設定」改。

- **聽得懂整句話**(需要在「設定」填 Claude API 金鑰):例如「下週三下午提醒我帶文件,前一天晚上也提醒一次」會拆成兩筆;缺資訊(幾點、哪一天)時會反問;也能問「今天有什麼事」「哪個時段有空」。
- **每一筆都可以復原**:助理建立提醒後,對話裡會列出來,按「復原」就刪掉。
- **主動提醒衝突**:建立後如果和既有排程重疊,會直接標出來。
- **語音對話**:按 🎤 用說的(使用手機內建的 Google 語音辨識,中文);打開「朗讀回覆」助理會用手機的語音唸出來;打開「連續對話」則在助理反問後自動打開麥克風等你回答。
- **每日確認也有個性**:簡報開頭是助理的問候、今天的件數與最長的空檔,並建議用空檔先處理哪件小任務,可按「🔊 朗讀」。
- 沒有金鑰時仍可使用:助理改用內建規則,聽得懂「明天下午3點到5點開會」這類固定說法,也能用語音輸入。
- 隱私:使用 AI 時,你目前的行程標題與時間會隨對話送到 Anthropic 的伺服器;不想送就不要填金鑰。

## 新介面與行程圖(v0.6)

- 深色優先的科技感配色(深藍底、青色主色、琥珀色代表小任務、紅色只留給衝突與過時),跟著手機的深/淺色模式。
- 底部導覽列:行程 / 助理 / 設定;鍵盤打開時會自動收起。
- 行程頁可切換「本日 / 本週 / 本月」,預設本日:
  - 本日:時間軸,色塊長度就是時段長短,重疊的並排顯示,空檔直接標出,有一條「現在」線;頂端卡片顯示下一件。
  - 本週:週一到週日七列,一眼看出哪天滿、哪天空;點某一天跳到該日時間軸。
  - 本月:月曆,顏色越深代表當天越忙,點日期在下方看清單。
- 沒有時間的小任務集中放在行程頁下方。

## 賈維斯助理功能(v0.7)

- 鬧鐘預設改成語音播報(設定 → 鬧鐘響法,可改回鈴聲或鈴聲加語音)。
- 睡前預告明天(21:30):第一件事、建議起床與就寢時間,一鍵設起床鬧鐘。
- 傍晚追問(18:30):過時沒完成的事,完成了 / 改到明天 / 刪除。
- 每週回顧(週日 20:00):每天排程時數、完成率、開會時數與建議。
- 用說的改、刪行程,排空檔,一律先確認。
- 從 LINE 等 App 分享文字或圖片進來、拍照建行程:先顯示確認卡。
- 台灣 2026–2027 國定假日與連假標示;重複項目可設「假日跳過」與結束日。
- 課表:手動或拍照輸入,每週重複、不響鈴,到寒假前一天。
- 備份、還原、匯出行事曆(.ics)。

## 開發

- Kotlin + Jetpack Compose,最低 Android 8.0(API 26)。
- 本機編譯:`gradle assembleDebug`(需要 Android SDK 與 JDK 17)。
- `app/debug.keystore` 是公開的除錯簽章金鑰,只用來讓每次編譯的簽章一致,不要拿來上架。
